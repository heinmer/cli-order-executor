```
!help [command]
```

Displays all available commands with links to the docs and repository, or details about the specified command.

---

### Parameters

- `command` — command name (with or without `!`)

---

### All variations

```
!help                     — displays all available commands with links to the docs and repository
!help [command]           — displays details about the specified command
```

---

### Examples

```
!help sl
```

This command displays details about the `!sl` command.
